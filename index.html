📘 Пошаговая инструкция: Как сделать свой сайт и выложить на GitHub Pages

1

Создайте аккаунт на GitHub

Перейдите на github.com и зарегистрируйтесь (Sign Up). Обязательно подтвердите свою электронную почту.

2

Создайте новый публичный репозиторий

В правом верхнем углу нажмите + → New repository:

  • Repository name: укажите название латиницей (например, ai-comments).
  • Public: обязательно выберите публичный доступ Public.
  • Поставьте галочку Add a README file и нажмите Create repository.
3

Загрузите файл index.html

В репозитории нажмите Add file → Upload files, перетащите файл index.html и нажмите зелёную кнопку Commit changes.

4

Включите хостинг GitHub Pages

Откройте вкладку Settings → слева раздел Pages → в пункте Branch выберите main и нажмите Save. Через 1–2 минуты ваш сайт заработает по адресу:

https://ваш-логин.github.io/название-репозитория/
